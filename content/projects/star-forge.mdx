## Why I Built This

I wanted a template that balances premium visual design with practical conversion structure.

## How It Works

The page guides users through value proposition, trust cues, and action blocks with clear hierarchy.

![StarForge hero](/projects-images/star-forge/screen1.jpeg)

## Key Decisions

- Keep typography and spacing highly intentional.
- Use motion only where it supports narrative flow.
- Build sections as reusable composition blocks.

## What I Learned

Conversion improves when visual direction and information architecture reinforce each other.
